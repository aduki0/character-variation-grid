# character-variation-grid

## 立ち絵差分一覧つくるくん

### このツールについて

立ち絵フォルダ内の画像から、表情差分などの一覧画像を作成するツールです。

すべてブラウザ上で動作し、画像やフォント情報が外部サーバーに送信されることはありません。

### 推奨環境

* Google Chrome または Microsoft Edge の最新版を推奨します。
* 動作確認は Windows 11 のPC環境でのみ行っています。
  その他のOS（Windows 10以前 / macOS / Linux等）では未確認のため、表示崩れや一部機能の不具合が起こる可能性があります。
* PC以外（スマートフォン・タブレット）での動作確認は行っておりません。
* 「フォント一覧取得」ボタンは、ローカルにインストールされたフォントを読み込む機能（Local Font Access API）を使用しています。
* Local Font Access API は Chrome / Edge系ブラウザのみ対応です。
  Firefox / Safariでは非対応のため、その場合は標準のフォント（sans-serif等）のみ選択可能です。
* この機能はセキュリティ上の理由から、HTTPS環境または localhost でのみ動作します。
  HTMLファイルを `file://` で直接開いた場合は動作しないことがあります。
  その他の機能には影響しません。

### フォント機能について

「フォント一覧取得」を押すと、ブラウザが許可確認のポップアップを表示します。

許可すると、お使いのPCにインストールされているフォントの名前一覧を取得し、画面のプルダウンに表示します。

* 取得したフォント名は、一覧表示・プレビューにのみ使用します。
* 取得したフォント名を外部に送信・保存することはありません。
* フォントの実体（ファイル）は、このツールには一切含まれていません。
* プルダウンから選択したフォントは、ユーザーのPCにすでにインストールされているフォントをブラウザが描画に使用するだけです。

### 画像データの取り扱いについて

選択したフォルダ内の画像は、すべてブラウザ内（お使いのPC上）でのみ処理されます。

サーバーへのアップロードは一切行われません。
