立ち絵差分一覧つくるくん

📄 README（はじめにお読みください）

このツールについて

立ち絵フォルダ内の画像から、表情差分などの一覧画像を作成するツールです。すべてブラウザ上で動作し、画像やフォント情報が外部サーバーに送信されることはありません。

推奨環境

  • Google Chrome または Microsoft Edge の最新版を推奨します。
  • 動作確認はPCWindows 11環境でのみ行っています。その他のOS（Windows 10以前 / mac OS / Linux等）では未確認のため、表示崩れや一部機能の不具合が起こる可能性があります。
  • PC以外（スマートフォン・タブレット）での動作確認は行っておりません。
  • 「フォント一覧取得」ボタンはローカルにインストールされたフォントを読み込む機能（Local Font Access API）を使用しており、Chrome / Edge系ブラウザのみ対応です。Firefox / Safariでは非対応のため、その場合は標準のフォント（sans-serif等）のみ選択可能です。
  • この機能はセキュリティ上の理由から「HTTPS環境」または「localhost」でのみ動作します。HTMLファイルをfile://で直接開いた場合は動作しないことがあります（その他の機能には影響しません）。

フォント機能について（プライバシーに関する補足）

  • 「フォント一覧取得」を押すとブラウザが許可確認のポップアップを表示します。許可すると、お使いのPCにインストールされているフォントの名前一覧を取得し、画面のプルダウンに表示します。
  • 取得したフォント名は一覧表示・プレビューにのみ使用し、外部に送信・保存することはありません。
  • フォントの実体（ファイル）はこのツールには一切含まれていません。プルダウンから選んだフォントは、あくまで「PCにインストールされているフォント」をブラウザが描画に使うのみとなります。

画像データの取り扱いについて

  • 選択したフォルダ内の画像はすべてブラウザ内（お使いのPC上）でのみ処理されます。サーバーへのアップロードは一切行われません。

📝 使い方

  1. 「フォルダを選択」から、立ち絵差分が入ったフォルダを読み込みます。
    ※選択フォルダ直下の画像のみ読み込まれます。サブフォルダの内容は含まれません。
  2. 左側に表示された立ち絵の上をドラッグして、一覧にしたい顔部分を囲みます。
  3. 選択した赤枠は調整できます。
    • 枠内をドラッグ：位置を移動
    • 右下の■：拡大・縮小
    • 青い丸：回転
  4. 右側に各差分のプレビューが表示されます。
    • ドラッグ＆ドロップ：並び替え
    • チェックを外す：一覧から除外
  5. 列数・サムネイルサイズ・余白・背景色・文字サイズなどをお好みで調整します。
    サムネイルサイズは 200～400px、文字サイズ20px前後がおすすめです。
  6. 「グリッド生成」を押すと、完成イメージが表示されます。
  7. OKであれば 「PNG保存」で一覧画像を保存します。

▸補足

  • 差分名には画像のファイル名が自動的に使用されます。
  • 「チャパレ用テキストDL」から、並べた順番の差分名一覧のテキストファイルも保存できます。
  • 「フォント一覧取得」を押すと、PCにインストールされているフォントを選択できるようになります。

※選択したフォルダの直下にある画像のみ読み込まれます（サブフォルダ内は含まれません）
